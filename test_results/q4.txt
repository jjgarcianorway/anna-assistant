[2m│ With the Simple Orca Plugin System (SOPS) you can extend the functionality of the Orca screen reader (orca).[0m
[2m│ It offers the possibility to add plug-ins in nearly any programming language in an easy way.[0m
[2m│ The settings for the plug-ins are controlled via the filename.[0m
[2m│ [0m
[2m│ [0m
[2m│ Installation[0m
[2m│ Install the package simpleorcapluginsystem-gitAUR.[0m
[2m│ [0m
[2m│ To setup the plug-in system for the current user, run:[0m
[2m│ [0m
[2m│ $ /usr/share/SOPS/install-for-current-user.sh[0m
[2m│ [0m
[2m│ Administration[0m
[2m│ Basics[0m
[2m│ The Installation path. This contains the default plug-ins, the documentation,the plugin loader and the administration tools:[0m
[2m│ /usr/s...[0m
[2m│ [0m
[2m│ ## !/bin/sh[0m
[2m│ echo "Hello World"[0m
[2m│ Advanced plug-ins[0m
[2m│ Those type of plug-ins are loaded with the spec.loader.exec_module. you can load them by using loadmodule in the filename. They are fully included into Orca as soon as it starts.[0m
[2m│ Advanced plug-ins are more powerful, because you are able to work in the Orca context. They are mostly similar to the orca-customizations.py.[0m
[2m│ [0m
[2m│ Requirements[0m
[2m│ [0m
[2m│ Correct code written in python3[0m
[2m│ Fileextension .py[0m
[2m│ [0m
[2m│ Use loadmodule in the filename[0m
[2m│ [0m
[2m│ key_<key> or exec have to been defined in filename[0m
[2m│ [0m
[2m│ Example[0m
[2m│ Configure Orca to speak/braille the word "bang" instead of the "!" while loading the plug-in.[0m
[2m│ Filename:replace_chnames__-__loadmodule__+__exec.py[0m
[2m│ [0m
[2m│ import orca.orca[0m
[2m│ orca.chnames.chnames["!"] = "bang"[0m
[2m│ Plug-in hosting[0m
[2m│ You can also host plug-ins, making them available for installation via the plug-in manager.[0m
[2m│ If you want to Host plug-ins, read:[0m
[2m│ /usr/share/SOPS/tools/hosting.txt[0m
