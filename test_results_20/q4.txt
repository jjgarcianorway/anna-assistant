[2m│ [0m
[2m│ Yandex.Disk is a free cloud storage service created by Yandex that gives you access to your photos, videos and documents from any internet-enabled device.[0m
[2m│ The official Yandex.Disk console client lets you:[0m
[2m│ [0m
[2m│ [0m
[2m│ synchronize files and folders with your Disk,[0m
[2m│ get public links to files and folders,[0m
[2m│ customize folder syncing.[0m
[2m│ [0m
[2m│ [0m
[2m│ Installation[0m
[2m│ Install the yandex-diskAUR package. Note that it is a CLI client — there is no official GUI for it at the moment. For alternatives see #Unofficial clients.[0m
[2m│ [0m
[2m│ To setup your proxy, user and local folder, enter[0m
[2m│ [0m
[2m│ $ yandex-disk setup[0m
[2m│ [0m
[2m│ Syncing will start after completing this step, now you are ready to use Yandex.Disk.[0m
[2m│ [0m
[2m│ Commands[0m
[2m│ You can manage your folder using any file manager or console.[0m
[2m│ [0m
[2m│ Full list of commands is available in man yandex-disk or using[0m
[2m│ [0m
[2m│ $ yandex-disk --help[0m
[2m│ [0m
[2m│ Here are some examples of use:[0m
[2m│ [0m
[2m│ [0m
[2m│ [0m
[2m│ setup — Launch the setup wizard.[0m
[2m│ [0m
[2m│ start — Launch the daemon and start...[0m

[2m│ [0m
[2m│ ## edquota -p user1 $(awk -F: '$3 > 999 {print $1}' /etc/passwd)[0m
